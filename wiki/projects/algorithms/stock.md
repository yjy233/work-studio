# 122 · 买卖股票 II

## 约束决定算法

允许多次交易，同时最多持有一股，没有手续费和冷冻期。目标是最大利润。这些条件改变后，当前贪心解不一定成立。题目来源：[LeetCode · Best Time to Buy and Sell Stock II](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/)。

## 正向差值全部收集

任意一段从 a 买到 b 卖的收益，可以展开为相邻差值之和：`prices[b]-prices[a] = Σ(prices[i]-prices[i-1])`。负差值只会损失利润，在可自由交易的约束下可避开；所有正差值可由连续上升段的低点买、高点卖实现。

例 `[7,1,5,3,6,4]` 的差值是 `[-6,+4,-2,+3,-2]`，答案 4+3=7。没有要求同一天真的重复交易，连续上升段合并为一笔交易也等价。

## 正确性

任意合法交易方案的每笔利润都能拆成相邻差值，因此总利润不可能超过全部正差值之和。另一方面，把每段严格上升趋势从开头买到末尾卖，可以取得恰好这个和。给出了上界，也给出了达到上界的合法方案，所以最优。

## 实现

```ts
function maxProfit(prices: readonly number[]): number {
  let profit = 0;
  for (let i = 1; i < prices.length; i++) {
    profit += Math.max(0, prices[i] - prices[i - 1]);
  }
  return profit;
}
```

时间 O(n)，额外空间 O(1)。单元素和空数组返回 0；持续下降返回 0；相等价格贡献 0。

## 三个追问

- 只能交易一次：不能收集所有上涨，需要维护历史最低价与最佳单次收益。
- 每笔交易有费用：把连续收益拆成多笔会重复付费，可考虑持有/未持有的 DP。
- 有冷冻期：卖出后不是下一天想买就能买，状态要表达休息限制。

测试把当前贪心结果与独立的持仓 / 现金动态规划对照，验证两种建模在当前约束下相符。
